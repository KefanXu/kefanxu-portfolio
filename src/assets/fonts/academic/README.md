# Website fonts

These unmodified Latin WOFF2 subsets were downloaded from the official Google
Fonts service on 2026-09-13. They are served locally and referenced through Vite
asset URLs in `src/styles/fonts.css`.

- **Crimson Text**, normal 400, italic 400, normal 600: SIL Open Font License 1.1;
  see `Crimson-Text-OFL.txt`.
- **DM Sans**, normal variable 400–700: SIL Open Font License 1.1;
  see `DM-Sans-OFL.txt`.
- **Homemade Apple**, normal 400: Apache License 2.0;
  see `Homemade-Apple-LICENSE.txt`.
